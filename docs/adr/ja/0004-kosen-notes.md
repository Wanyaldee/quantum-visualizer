# 0004: 香川高専のシラバスから「高専では」の欄を加える

[English](../en/0004-kosen-notes.md)

## Context（背景）

ワークショップは高専で行います。高専生は高校生と同じ年代で大学の数学（線形代数、固有値、微分方程式、フーリエ解析）を学ぶので、ADR 0003 の高校向けの説明だけでは、すでに知っている内容を十分に拾えません。参考にするものとして、ユーザーから [香川高専 電気情報工学科の令和7年度シラバス](https://syllabus.kosen-k.go.jp/Pages/PublicSubjects?school_id=39&department_id=32&year=2025&lang=ja) を指定されました。

## Decision（決定）

- `Slide.kosen`（省略可）を、同じ囲みの中で高校の説明の下に「高専では」として表示する。どの説明にも、シラバスにある実際の科目名と学年を書く。
- 基礎ページの冒頭で、科目名の出典を示し、シラバスへリンクする。

## Reason（理由）

**`school` に文を足すのではなく、別のフィールドにする。**

```tsx
{
  slide.kosen && (
    <div className="school-kosen">
      <p className="school-tag">高専では</p>
      {slide.kosen}
    </div>
  );
}
```

- 高校生と高専生が、それぞれ自分向けの行を見つけられる。高校向けの説明がないスライド（ゲート式ガイドの「ここで測ると」）でも、高専向けの行だけを出せる。

**どの記述も、シラバスのページかコードと照らし合わせた。**

- 引用した科目は、どれも週ごとの授業計画を読んで確かめた。例: 電気基礎（3年）の第6週・第13〜15週（複素平面・オイラーの式・正弦波の合成）、制御工学（4年）の第7週（ボード線図）。
- チーム分けのプリセット: 6 人を 3 人ずつに分け、佐藤さんを固定するので、残り 5 人から A に入る 2 人を選ぶ。ルールを守る答えは ₅C₂ = 10 通りで、2⁵ = 32 通りのうちの一部。
- 測定: B(1000, 1/2) の標準偏差は √(1000·¼) ≈ 15.8。
- アニーリング: H(s) は時間とともに変わるので、「定数係数」ではなく「ルンゲ＝クッタ法で数値的に解く線形微分方程式」と書いた（`evolve` は RK4）。
- ゲート: 基底状態に対して、cx は「相手 ← 相手 XOR 制御」、ccx は「相手 ← 相手 XOR (a AND b)」。

## Alternatives rejected（採用しなかった案）

- 高校向けの説明を高専向けに置き換える：このサイトはこのワークショップ以外でも使われる。
- 「大学の線形代数」のような一般的な書き方：実際の科目名と学年を書くことで、「それ去年やった」と思ってもらえる。この機能の狙いはそこにある。

## Consequences（結果・影響）

- 説明の内容は、令和7年度の香川高専 電気情報工学科のもの。ほかの高専や学科、別の年度では、科目名や学年が違うことがある。
- 半導体物理と制御工学は選択科目で、表にもそう書いている。
